# CatchFrame Media

האתר של CatchFrame Media, סטודיו לסרטוני AI, תסריטים וסיפורים ויזואליים.

- כתובת: https://catchframemedia.com
- אתר סטטי (HTML/CSS/JS), מתארח ב-GitHub Pages.
- עבודות בגלריה: מוגדרות במערך `P` בתוך `index.html`. לכל עבודה עם סרטון מספיק מזהה היוטיוב (`v`), ותמונת הכיסוי נלקחת אוטומטית מיוטיוב.

**חשוב:** כרטיסי הגלריה כתובים ישירות ב-HTML (בתוך `<div id="grid">`) כדי שגוגל וכלי AI יוכלו לקרוא אותם. כשמוסיפים עבודה למערך `P`, צריך להוסיף גם כרטיס תואם עם `data-i` לפי המיקום במערך.
